# Dreamy in Savannah

Minimal Next.js redirect project for DreamyInSavannah.com.

Visitors to the homepage are permanently redirected to:

https://www.airbnb.com/rooms/36699311

## Deploy

1. Push this project to GitHub.
2. Import the repo into Vercel.
3. Add `dreamyinsavannah.com` and `www.dreamyinsavannah.com` in Vercel Project Settings → Domains.
